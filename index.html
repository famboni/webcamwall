Settings

API keys are stored in this browser only — they are never sent anywhere except to the service they belong to.

Windy webcams API key

A key is already filled in for you, so Windy works out of the box. To use your own instead, get a free key at api.windy.com/keys (choose the Webcams API), paste it above and press Save & connect.

Camera sources

Local cams come from the public online-australia.net NZ webcam directory — council, surf-club and community cameras that NZTA and Windy don't cover. Each image stays hosted by whoever runs that camera, and every tile links back to its source.

Your wall

Your layout is stored in this browser. Create a portable copy here to move it to another browser or device. Removing every camera leaves your settings alone.

Backup & restore

The backup includes your pinned cameras, titles, order, tile sizes, display preferences, and custom-camera URLs. Your Windy API key and temporary camera-list cache are never included.

Restoring replaces the current wall and restores the display preferences, but keeps this browser's Windy API key. Custom camera URLs are included; only restore backups you trust, and keep them private if those URLs contain access tokens.

Camera lists

Re-reads cameras.json (NZTA road cameras) and webcams.json (local directory) from this website, so newly added cameras show up without a rebuild.
